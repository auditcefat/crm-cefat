Sauvegarde & Restauration

L'export/import permet de partager les données entre les postes de travail. Workflow recommandé : chaque matin, la personne responsable exporte le JSON et le dépose dans un dossier partagé (Teams, OneDrive, Dropbox) ; les collaborateurs importent avant de commencer.

📱 Utilisation sur mobile & hébergement

Sur mobile (iOS / Android)

1. Ouvrez le fichier HTML dans Chrome ou Safari
2. Appuyez sur Partager → Ajouter à l'écran d'accueil
3. L'app apparaît comme une icône sur votre téléphone
4. Elle fonctionne hors connexion, les données restent dans le navigateur

Hébergement partagé (solution durable)

Pour éviter tout risque de perte et permettre à tous d'accéder aux mêmes données en temps réel, la meilleure solution est de déposer le fichier HTML sur un serveur web interne ou un service comme GitHub Pages (gratuit). Chaque collaborateur accède alors à la même URL depuis son PC ou téléphone.

En attendant : déposez le fichier dans un dossier OneDrive / SharePoint partagé avec vos collaborateurs et utilisez l'export/import JSON pour synchroniser les données.
